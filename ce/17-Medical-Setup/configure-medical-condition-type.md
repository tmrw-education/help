# Configure Medical Condition Type

Medical condition type classifies a condition as **Chronic** or **Acute**. It is
master data — set once and used consistently by every medical detail record, so
that reporting across the school holds together.

1. Open the configuration

   Open the medical condition type configuration in the master data area.

2. Check the values

   Confirm the picklist holds the values your schools use — at minimum Chronic
   and Acute.

   ![The medical condition type picklist values](./images/configure-medical-condition-type-1.png)

3. Add or amend

   Add or amend values as needed and save.

   > **Note:** Changing master data affects every existing record that uses it.
   > Removing a value in use will leave historic records pointing at nothing —
   > deactivate rather than delete.
