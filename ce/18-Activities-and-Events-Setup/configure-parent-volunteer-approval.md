# Configure parent volunteer approval

Where an activity needs parents to help out, the event record holds both the
requirement and the list of volunteers who have been accepted.

1. Flag the requirement

   Open the event and set **Required school volunteer** to **Yes**. A field
   appears for the number of parent volunteers required — set the limit.

   ![The required school volunteer flag with the volunteer limit set](./images/configure-parent-volunteer-approval-1.png)

   > **Note:** Setting the flag to No hides the limit field again.

2. Add the volunteers

   Parent volunteers are added through **Resource booking**, under the event team
   member booking. Add the parent, then set the **Member type** to **Parent
   volunteer**.

   ![Adding a parent as an event team member with member type parent volunteer](./images/configure-parent-volunteer-approval-2.png)

3. Check against the limit

   Compare the volunteers added against the number required on the event.
