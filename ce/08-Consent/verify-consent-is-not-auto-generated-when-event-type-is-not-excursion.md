# Check that consent isn't created for non-excursion event types

Auto-registration — and the consent that follows it — is deliberately limited to the **Visit** and **Excursion** event types. This check confirms that an event of any other type does not auto-register students and therefore does not auto-generate consent.

1. Open an event with a non-excursion type

   In the **Events and Excursions** area, open (or click **New** to create) an event and set **Event type** to something other than **Excursion** or **Visit** — for example **Co-curricular**, **Corporate**, or Camp. 2. Select a year group and roll group

   In the **Attendee** section, choose a **Year group** and roll group as you would for an excursion. For Visit and Excursion this selection auto-registers the matching students; for every other event type it does not.

3. Confirm no students were auto-registered

   Check the registration list on the event: it should stay empty. Because no students are registered, no consent is generated for this event. Registration for non-excursion event types must be done manually.
