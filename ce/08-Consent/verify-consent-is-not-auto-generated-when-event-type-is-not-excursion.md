# Check that consent isn't created for non-excursion event types

Auto-registration — and the consent that follows it — is deliberately limited to
the **Visit** and **Excursion** event types. This check confirms that an event of
any other type does not auto-register students and therefore does not
auto-generate consent.

1. Open an event with a non-excursion type

   In the **Events and Excursions** area, open or create an event and set
   **Event type** to something other than **Excursion** or **Visit** — for example
   **Co-curricular**, **Corporate** or Camp.

   ![The event header with Event type set to a non-excursion type such as Co-curricular](./images/verify-consent-is-not-auto-generated-when-event-type-is-not-excursion-1.png)

2. Select a year group and roll group

   In the **Attendee** section, choose a **Year group** and roll group as you
   would for an excursion.

3. Confirm no students were auto-registered

   Check the registration list on the event — it should stay empty. Because no
   students are registered, no consent is generated.

   > **Note:** Registration for non-excursion event types has to be done manually.
   > An empty list here is the expected result, not a fault.

   ![The event's empty registration list for a non-excursion event type](./images/verify-consent-is-not-auto-generated-when-event-type-is-not-excursion-2.png)
