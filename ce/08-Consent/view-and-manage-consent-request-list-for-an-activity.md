# View and manage the consent requests for an activity

Once an activity has generated consent, you can see the full list of consent
requests for it — who has been asked, who has responded, and what is still
outstanding — and follow up from one place.

1. Open the activity

   In the **Events and Excursions** area, open the event or excursion whose
   consent you want to review.

2. Open the consent request list

   On the activity, open its consent request list. Each row is one requested
   student, with their response status.

   ![The activity's consent request list showing each student and their response status](./images/view-and-manage-consent-request-list-for-an-activity-1.png)

3. Manage outstanding requests

   Use the list to identify students who have not yet responded, and follow up.

   > **Note:** Check this list before the activity runs, not on the day. An
   > outstanding consent is a student who cannot travel.
