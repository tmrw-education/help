# Rescind all consent for a student

This withdraws every consent currently held for a student in one pass — for
example when a parent withdraws blanket permission.

1. Open the student's Consent area

   In the CE model-driven app, open the student's profile and go to the
   **Consent** area, where all of that student's consent records are listed.

   ![The student's Consent area listing all active consent records](./images/rescind-all-consent-1.png)

2. Rescind every active consent

   Rescind each active consent held for the student.

3. Save

   Save so every consent shows as withdrawn.

   > **Note:** This is a significant action for a student — check it is what the
   > parent has actually asked for before applying it.
