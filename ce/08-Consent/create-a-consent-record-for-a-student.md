# Create a consent record for a student

Consent is captured against the student's profile in CE. A student can have
several consent records of different types — for example consent to share
information, consent to share achievements, or medical consent.

1. Open the student's profile

   In the CE model-driven app, open the student's profile and go to the
   **Consent** area. The student profile groups its information into areas —
   demographics, relationships, classroom management, well-being, achievement,
   **Consent**, and community/behaviour.

   ![The student profile with the Consent area open](./images/create-a-consent-record-for-a-student-1.png)

2. Add a new consent record

   Add a new consent record and choose the consent **type**. Different consent
   types are captured here — for example consent for information sharing, consent
   for achievement sharing, and medical consent.

3. Save the record

   Save the consent record against the student.
