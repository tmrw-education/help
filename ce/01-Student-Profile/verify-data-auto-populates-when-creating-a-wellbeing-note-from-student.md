# Verify data auto-populates when creating a Wellbeing Note from Student Profile

Starting a wellbeing note from the student's profile saves re-keying — the
student and their academic detail carry across to the new note automatically.

1. Start the note from the profile

   Open the student profile, go to the wellbeing section, and create a wellbeing
   note from there.

2. Check the student carried across

   Confirm the **Student profile** on the new note is already populated with the
   student you started from.

   ![A new wellbeing note with the student pre-filled from the profile](./images/verify-data-auto-populates-when-creating-a-wellbeing-note-from-student-1.png)

3. Check the academic detail

   Confirm the academic detail has carried across too.

   > **Note:** The **Year group** only populates if it is set on the student
   > profile. A blank year group on the note points at missing data on the
   > profile, not at a fault with the note.

4. Complete the note

   Fill in the rest of the note as normal — see
   [Create a wellbeing note and share](../04-Wellbeing/create-a-wellbeing-note-and-share.md).
