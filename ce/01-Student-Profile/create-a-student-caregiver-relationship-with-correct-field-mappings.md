# Create a student-caregiver relationship with correct field mappings

Relationships link a student to the adults responsible for them. Each
relationship records what that person is to the student, so that permissions and
contact rules can follow from it.

1. Open the relationship section

   Open the student profile and go to the relationship section, alongside the
   list of siblings.

2. Create the relationship

   Click **New relationship**.

3. Set the type and contact

   Choose the **Relationship type** — father, mother, caregiver and so on — then
   select the **Contact**.

   ![Creating a new relationship with the relationship type list open](./images/create-a-student-caregiver-relationship-with-correct-field-mappings-1.png)

4. Save

   Save the relationship.

   > **Note:** Who is permitted to add a caregiver is a live question — it was
   > raised during the design review and not settled. Check your school's process
   > before adding one.
