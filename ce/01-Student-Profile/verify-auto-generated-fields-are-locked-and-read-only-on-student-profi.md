# Verify auto-generated fields are locked and read-only on Student Profile

Some fields on the student profile are generated by the system — IDs and codes
that other systems rely on. These must be read-only, because editing one by hand
breaks the link to everything referencing it.

1. Find the generated fields

   Open the student profile and find the auto-generated fields, including the
   student ID.

2. Try to edit

   Attempt to change one.

   ![Auto-generated fields shown as read-only on the student profile](./images/verify-auto-generated-fields-are-locked-and-read-only-on-student-profi-1.png)

3. Confirm they are locked

   The field should not accept input.

   > **Note:** A field being editable in an administrator app does not always
   > mean it is meant to be. Some fields are left unlocked during development for
   > testing and should be locked before release — if you find one, raise it
   > rather than using it.
