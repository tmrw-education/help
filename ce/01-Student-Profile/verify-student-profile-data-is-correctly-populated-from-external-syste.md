# Verify Student Profile data is correctly populated from external system import

A student is held in two places. The **Contact** record holds personal
information that does not change as they move through the school. The **Student
profile** extends it with the academic detail for one academic year.

1. Open the contact

   Open the student's **Contact** record. It holds their personal information,
   plus legal identification, passport and visa detail.

2. Open the student profile

   Open the linked **Student profile**. This is the record that captures the
   student's journey for a single academic year.

   ![The student profile showing its tabs](./images/verify-student-profile-data-is-correctly-populated-from-external-syste-1.png)

3. Work through the tabs

   The student profile is organised into tabs covering demographics,
   relationships, classroom management, wellbeing, achievement, consent,
   community and behaviour. Check the imported values on each against the source.

   > **Note:** Because the profile is per academic year, a student has more than
   > one over time. Check you are looking at the right year before reporting a
   > value as wrong.
