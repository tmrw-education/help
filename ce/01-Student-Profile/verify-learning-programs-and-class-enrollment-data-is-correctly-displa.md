# Verify Learning Programs and Class Enrollment data is correctly displayed

The classroom management section shows which classes a student is enrolled in for
the academic year. The enrolments are generated from the enrolment and
re-enrolment process, not entered by hand.

1. Open classroom management

   Open the student profile and go to the classroom management section.

2. Check the classes

   Confirm the classes listed are the ones the student should be taking,
   including any optional subjects chosen during enrolment.

   ![The classroom management section on a student profile](./images/verify-learning-programs-and-class-enrollment-data-is-correctly-displa-1.png)

3. Check each class resolves

   Open a class and confirm it references the right course, year group and roll
   group — see
   [View teacher assignments](../12-Curriculum-Management/view-teacher-assignments.md)
   for what sits behind a class.

   > **Note:** Class student lists are populated automatically at the start of
   > the academic year. If a student is missing from a class, the problem is
   > usually upstream in enrolment rather than on the profile.
