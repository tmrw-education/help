# Record medication received from parents for school administration

Where a parent brings medication in for the school to administer, record it
before the first dose is given so that the instruction and the course dates are
on the system.

> **Note:** Medical centre records are restricted. Creating a visit record is
> limited to medical centre staff; viewing is limited to medical centre staff and
> the principal.

1. Create the medication record

   Add a medication record for the student.

2. Record what was received

   Set the **Medicine type**, **Dose**, **Medication unit**, **Frequency** and
   the **Instruction** given by the parent or prescriber.

3. Set the course dates

   Set the **Start date** and **End date** covering the period the school is
   expected to administer the medication.

   ![A medication record showing the course dates and instruction](./images/record-medication-received-from-parents-for-school-administration-1.png)

4. Save

   Save the record. Each dose actually given is then logged against it — see
   [Log medication administration](./log-medication-administration.md).
