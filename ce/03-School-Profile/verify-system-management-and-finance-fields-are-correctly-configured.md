# Verify System Management and Finance fields are correctly configured

Finance configuration varies by school — some charge an application fee, some
require a deposit, and schools in different countries work in different
currencies. Check the configuration matches the school before it drives any
payment request.

1. Open the finance tab

   Open the school profile and go to the **Finance** tab.

2. Check the flags

   Confirm the configuration flags are set correctly for this school:

   - Whether an **Application fee** is required
   - Whether a **Deposit** is required

   ![The Finance tab on a school profile showing the fee configuration flags](./images/verify-system-management-and-finance-fields-are-correctly-configured-1.png)

3. Check the visa types

   Confirm the visa types configured for the school are correct.

4. Check the fee and charge entries

   Open **School fee and charge**. Each entry links a fee category to an academic
   year, curriculum, year group and school, and is what payment requests are
   generated from.

   Check the **Currency** is right for the school's location.

   > **Note:** This area is actively changing. Payment links are moving to being
   > generated by finance and operations rather than by CE, and most fee amounts
   > beyond the application fee are expected to be driven from the ERP price list
   > rather than held here. Check the current position before relying on a value.
