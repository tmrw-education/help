# Create resource

Resources are the individual bookable items — a specific projector, a particular
minibus. They are set up in the back end and surfaced to staff for booking.

1. Open Resource scheduling

   In the **Administrator** app, select the **Resource scheduling** area and open
   the resources list.

2. Create the resource

   Click **New**, name the resource, and set its **Resource category** and brand.

   ![A new resource record with its category and brand set](./images/create-resource-1.png)

3. Save

   Save the record. The resource now appears in the list staff can book from in
   the Staff Experience Platform.

   > **Note:** Resources link through to the underlying bookable resource
   > records. If a resource is not appearing for booking, check that link before
   > recreating it.
