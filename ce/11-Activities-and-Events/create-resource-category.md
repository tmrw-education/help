# Create resource category

Resource categories group the things staff can book — audio-visual equipment,
sports gear, minibuses. Categories are what people filter by when they come to
book, so set these up before creating individual resources.

1. Open Resource scheduling

   In the **Administrator** app, select the **Resource scheduling** area.

2. Open the categories

   Go to the resource categories tab — the second tab in the area.

   ![The Resource scheduling area with the resource categories tab open](./images/create-resource-category-1.png)

3. Create the category

   Click **New**, name the category, and save.

   > **Note:** Categories and resources are both back-end setup. Staff booking
   > from the Staff Experience Platform can only pick from what already exists
   > here — they cannot create either.
