# Manage resource booking

The resource manager or IT help desk works through requested bookings, decides
which specific resource to allocate, and confirms.

1. Open the bookings

   In the **Administrator** app, select the **Resource scheduling** area and go
   to the bookings tab.

2. Review the requests

   Each booking shows the **Start time**, **End time** and duration requested.

   ![The bookings list showing start time, end time and duration](./images/manage-resource-booking-1.png)

3. Allocate and confirm

   Choose which resource to lend to the requester and confirm the booking.

   > **Note:** Where several staff have asked for the same category over the same
   > period, the allocation decision sits with whoever manages the resources —
   > the system does not decide for you.
