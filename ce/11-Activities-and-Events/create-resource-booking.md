# Create resource booking

A resource booking reserves a resource for a period. Bookings are created in the
back end — staff request resources through the Staff Experience Platform, but the
booking record itself lives here.

1. Open the bookings

   In the **Administrator** app, select the **Resource scheduling** area and go
   to the bookings tab — the third tab in the area.

   ![The bookings tab in the Resource scheduling area](./images/create-resource-booking-1.png)

2. Set the period

   Create the booking and set the **Start time**, **End time** and duration.

3. Select the resource

   Choose the resource being booked from the resources already set up.

4. Save

   Save the booking.

   > **Note:** Resource bookings cannot be created from the Staff Experience
   > Platform. Someone has to set the records up here in advance for staff to be
   > able to select them.
