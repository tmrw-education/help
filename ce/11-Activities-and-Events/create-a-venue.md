# Create a venue

Venues are held as their own records so they can be reused across events. Once a
venue is approved, selecting it on an event pulls its detail through
automatically.

1. Open the venue records

   Open the venue and building records and click **New**.

2. Set the basics

   Choose whether the venue is **Internal** or **External**, select the
   **School** it belongs to, and set the **Type**.

   ![A new venue record with internal/external, school and type set](./images/create-a-venue-1.png)

3. Save

   Save the record. An approval record is created against the venue
   automatically and routed to the approver defined on the approval matrix.

   > **Note:** A venue cannot be used on an event until it has been approved —
   > see [Approve a venue](./approve-a-venue.md).
