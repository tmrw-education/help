# Send a consent request to parents

Once a consent record exists — either created for a student or generated from an
activity — you issue it to the student's parents so they can respond.

1. Open the consent record

   In CE, open the consent record you want to issue, either from the student's
   **Consent** area or from an activity's consent request list.

2. Issue the request to parents

   Send the consent request to the student's parents.

   ![The consent record with the control that issues the request to parents](./images/send-issue-consent-to-parents-1.png)

3. Parents respond

   The parents respond to the request, and their response is stored back against
   the student's consent record — see
   [See a parent's consent response](./view-stored-consent-response-for-a-student.md).
