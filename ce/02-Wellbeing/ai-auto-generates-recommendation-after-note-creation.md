# AI auto-generates recommendation after note creation

Once a wellbeing note is saved with enough detail, an **AI recommendation** is
generated against it automatically. It suggests next steps based on what was
written in the note.

1. Create the note with full detail

   Create the wellbeing note and complete the **Description**, **Wellbeing note
   type**, **Sentiment** and **Priority**. The recommendation is generated from
   this information, so a thin description produces a thin recommendation.

2. Save and refresh

   Save the note. The recommendation is produced in the background — refresh the
   record if it has not appeared yet.

3. Read the recommendation

   The **AI recommendation** appears on the wellbeing note.

   ![The AI recommendation field on a saved wellbeing note](./images/ai-auto-generates-recommendation-after-note-creation-1.png)

   > **Note:** The recommendation is a prompt for the staff member handling the
   > case, not a decision. Professional judgement always takes precedence.
