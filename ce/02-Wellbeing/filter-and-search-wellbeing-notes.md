# Filter and search wellbeing notes

The wellbeing notes list can be filtered on any column, and filters can be
combined. This is also how you build the result set before exporting — see
[Export wellbeing notes to Excel](./export-wellbeing-notes-to-excel.md).

1. Open the Wellbeing notes list

   In the **Wellbeing** area, open **All Wellbeing Notes**. Click the three-line filter icon in the top-right corner.

2. Add a filter row

   Click the **+ Add** dropdown to start a filter, then choose the column you want to
   filter on.

   ![The wellbeing notes list with the filter panel open and Add row selected](./images/filter-and-search-wellbeing-notes-1.png)

3. Set the condition

   Choose the **Field**, **Operator** and the **Value**. Commonly used filters are:

   - **Wellbeing Note Type** defines the type, for example, Environmental safety
   - **Priority** defines the priority nature of the wellbeing note
   - **Student profile** refers to a named student
   - **Created on** — search for a note created on, before or after a specific date
   - **Status** to bring up only Active notes

   ![Weelbeing note search filter options](./images/filter-and-search-wellbeing-notes-2.png)

4. Apply and combine

   Click **Apply**. Add further rows to narrow the results — for example
   priority High *and* status Active.
