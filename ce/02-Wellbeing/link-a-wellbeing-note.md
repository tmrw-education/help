# Link a wellbeing note

Linking notes connects related concerns about the same student so that whoever
picks up the case can see the pattern rather than a single isolated incident.

1. Open the note

   Open the wellbeing note you want to link from.

2. Add the link

   In the **Link** section, search for the note you want to connect and select
   it.

   ![The Link section on a wellbeing note with a related note selected](./images/link-a-wellbeing-note-1.png)

3. Add more if needed

   Repeat to attach further notes — a note can be linked to more than one
   related record.

4. Save

   Click **Save**. The linked notes are now reachable from either record.

   > **Note:** Linked notes are usually about the same student, but the link
   > itself is not restricted to one student. Check you have selected the right
   > record before saving.
