# View wellbeing note details

A wellbeing note holds the record of the concern; the wellbeing case attached to
it holds the follow-up. This page covers what you see on each.

1. Open the note

   In the **Wellbeing** area, open **Wellbeing notes** and select the note.

2. Read the note detail

   The note shows:

   - **Name** — the title of the note
   - **Student profile** — the student the note is about
   - **Wellbeing note type** — Physical, Mental, Social, Emotional, Academic and so on
   - **Sentiment** — Positive, Neutral or Negative
   - **Priority**
   - **Notify parents** and, where set, the **Parent profile**
   - **Description** — the detail written when the note was raised
   - **AI recommendation** — generated automatically after the note is saved

   ![A wellbeing note showing student, type, sentiment, priority and description](./images/view-wellbeing-note-details-1.png)

3. Open the linked case

   Open the **wellbeing case** created against the note. The case carries the
   **Priority**, the **Status**, the owner, and a **Timeline** holding comments,
   notes and tasks.

   > **Note:** Notes raised in SXP and notes raised in CE look the same here.
   > The case is created the same way either way.

   ![The linked wellbeing case with its timeline and status](./images/view-wellbeing-note-details-2.png)
