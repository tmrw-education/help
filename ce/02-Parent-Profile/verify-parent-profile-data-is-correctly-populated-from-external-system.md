# Verify Parent Profile data is correctly populated from external system import

Parent profiles are normally populated during registration: a parent completes
the online registration form, and the form's detail is captured and input into
the system automatically. This checks that the imported data lands on the correct
fields of the parent profile.

1. Open the Administrator app

   From the **App selector** in the top-left menu, choose the **Administrator**
   app, and make sure the **Student** session is selected in the bottom-left of
   the screen.

2. Open the imported parent profile

   In the **General** menu, select **Parent profile**. Use **Search** and
   **Filter** to find the profile created from registration, then **Open** it.

   ![The Parent profile list with Search and Filter](./images/verify-parent-profile-data-is-correctly-populated-from-external-system-1.png)

3. Confirm the imported detail is populated

   Confirm the name and basic information the parent entered in the online form
   have been captured onto the profile, on the correct fields.

   > **Note:** When a profile is not created through online registration, staff
   > enter the same details manually against a new **Contact** record.
