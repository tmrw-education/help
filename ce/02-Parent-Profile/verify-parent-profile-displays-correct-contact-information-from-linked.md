# Verify Parent Profile displays correct Contact information from linked Contact record

A parent profile is built on top of a **Contact** record: the person's name and
basic details live on the Contact, and the parent profile reads them from that
linked Contact. This checks that the contact information shown on a parent
profile matches its linked Contact record.

1. Open the Administrator app

   From the **App selector** in the top-left menu, choose the **Administrator**
   app, and make sure the **Student** session is selected in the bottom-left of
   the screen.

   ![The App selector open with the Administrator app selected](./images/verify-parent-profile-displays-correct-contact-information-from-linked-1.png)

2. Open the Parent profile list

   In the **General** menu, select **Parent profile**. You can **Search** and
   **Filter** the list, and **Open** any record to see its detail. To add a new
   record, use **New**.

3. Create the linked Contact first

   A new parent profile starts by creating a **Contact** to capture the person in
   the system. Enter the **Name** and the basic information, then **Save & close**.
   This creates the Contact record that the parent profile links to.

4. Confirm the contact information on the parent profile

   Open the parent profile and confirm the name and basic information displayed
   match the linked **Contact** record — the parent profile reads these values
   from the Contact rather than storing its own copy.

   > **Note:** During registration these details are entered by the parent in the
   > online form and captured into the system automatically. When you create a
   > profile by hand, you enter the same details manually.
