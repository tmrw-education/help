# Verify legal and background data fields are correctly populated on Parent Profile

Once a parent profile is created, capture the detail that relates to the parent
record: the flags on the main form, the parent's identity documents on the
**Legal** tab, and their employment and donor status on the **Background** tab.
This checks those fields are populated correctly.

1. Open the parent profile

   From the **App selector**, open the **Administrator** app, go to **General →
   Parent profile**, and open the record you want to check.

2. Set the flags on the main form

   Set **E-Stop** to **Yes** or **No** — when it is **Yes**, a **Staff ID** can be
   selected. Set the **Communication channel** to the appropriate language for
   communicating with the parent, and set the flags for whether the parent belongs
   to a **family** or **diplomatic family** (**Yes / No**).

   ![The parent profile main form showing the E-Stop and communication flags](./images/verify-legal-and-background-data-fields-are-correctly-populated-on-par-1.png)

3. Enter Legal document data

   On the **Legal** tab, enter the parent's **Document** data — their identity
   document details.

4. Enter Background data

   On the **Background** tab, enter the **Occupation group** and the **Employee**
   data, where available. Set the **Donor** flag (**Yes / No**) to record whether
   the parent has recently been involved in donor or charity activity.

5. Save and clear any required fields

   Click **Save**. If any required field is missing, an error is shown — for
   example, the **Emergency ranking** address, which sets the priority order the
   school uses to reach the parent during a situation. Once every required field
   is added, click **Save** again to finish creating the parent profile.

   > **Note:** This profile is reused across multiple functions — for example,
   > event registration and the parent portal. Medical details and consent are
   > linked to the profile once it has been generated.
