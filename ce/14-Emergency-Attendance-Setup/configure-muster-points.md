# Configure Muster Points

A muster point is where a roll group assembles when an emergency is declared. It
is held against the roll group, so every roll group needs one before an emergency
happens — not during.

1. Open the roll group

   Open the roll group you want to configure.

2. Set the muster point

   Set the **Muster point** for that roll group — the location its students
   assemble at.

   ![A roll group record with the muster point field set](./images/configure-muster-points-1.png)

3. Repeat across the school

   Work through every roll group. Any roll group without a muster point leaves
   its students without an assembly location when an emergency is declared.

   > **Note:** Muster points feed straight into emergency attendance records, so
   > getting this right in advance is what makes the emergency roll usable.
