# Define assessment items for a course

Assessment items are the assignments, tests and activities a teacher will use to
assess students on a course. Defining them in CE means they can be pushed out to
Teams Edu and the results pulled back in without anyone re-keying data.

1. Open the assessments

   Open the program plan and go to the **Teacher assessment** section. Click
   **New**.

   ![The Teacher assessment section on a program plan](./images/define-assessment-items-for-a-course-1.png)

2. Describe the assessment

   Enter the **Assessment title** and choose the **Assessment type**.

3. Set the marking and dates

   Set the **Max points** available, the **Weight** the assessment carries, the
   **Assign date** and the **Due date**.

   ![The teacher assessment form with max points, weight and dates](./images/define-assessment-items-for-a-course-2.png)

4. Set the status and save

   Set the **Status**, then click **Save**.

   > **Note:** Each class under the course carries its own teacher assessment
   > records. Assessments defined on the program plan set the pattern; the class
   > holds what was actually assigned to those students.

5. Push it to Teams

   Assessment items sync both ways with Teams Edu — see
   [Manual sync from Teams to CE](./manual-sync-from-teams-to-ce.md).
