# Create a master program plan for each course

A program plan is the plan a teacher delivers for a course in a given academic
year. CE holds the plan record and a link to the master document, so there is a
single source of truth even when individual teachers adapt it for their own
class.

Program plans sit under **Curriculum Management** in the **Administrator** app,
alongside curricula, courses and classes. This area is normally reserved for
school leaders rather than classroom teachers.

1. Open Program plans

   In the **Administrator** app, open the **Curriculum Management** area and go
   to **Program plans**. Click **New**.

   ![The Curriculum Management area with Program plans selected](./images/create-a-master-program-plan-for-each-course-1.png)

2. Name the plan and set its scope

   Enter a name for the plan — for example *Mathematics Year 3*. Then select the
   **School profile**, the **Academic year**, the **Term** and the **Course**
   the plan belongs to.

   > **Note:** The **Course** list is driven by the curriculum. If the course you
   > need is missing, it has to be created under the curriculum first.

3. Link the master document

   Add the **Program plan URL**. This points to the approved master program
   document that teachers and students work from.

   ![The program plan form showing the course, academic year and program plan URL](./images/create-a-master-program-plan-for-each-course-2.png)

4. Set the status and save

   Set the **Status** — for example Draft while it is being written, or Active
   once it is approved — and click **Save**.

   Submission details and approval status appear at the foot of the form. These
   record the exchange between the teacher who drafts the plan and the head of
   subject who approves it.

5. Add the assessment items

   With the plan saved, define what students will be assessed on — see
   [Define assessment items for a course](./define-assessment-items-for-a-course.md).
