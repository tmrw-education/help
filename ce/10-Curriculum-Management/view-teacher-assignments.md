# View teacher assignments

Every assignment a teacher sets in Teams appears in CE as a teacher assessment
record against the class. This gives leaders a view of what has been set across
classes without needing to be a member of each Team.

1. Open the class

   In the **Administrator** app, open **Curriculum Management**, go to
   **Classes** and open the class.

2. Open the assessments

   Go to **Teacher assessment**. Each record is one assignment or assessment set
   for that class.

   ![The teacher assessment list on a class record](./images/view-teacher-assignments-1.png)

3. Open an individual assessment

   Open a record to see its instructions, **Assessment type**, **Max points**,
   **Assign date** and **Due date**, along with the student submissions.

   > **Note:** Assignments only appear once the class has been synced. If the
   > list is empty, check the class has a Teams URL stored against it.
