# View student submissions

Once an assignment has synced from Teams, CE shows which students have turned
work in and what they scored. This is the view to use when you want the picture
across a class without going into Teams.

1. Open the class assessment

   Open the class in **Curriculum Management**, go to **Teacher assessment** and
   open the assessment you want to check.

2. Read the submission list

   The list shows each student on the assignment. For each one you can see:

   - **Assigned date** — when the work was set
   - **Submit date** — when the student turned it in, blank if they have not
   - **Published point** — the mark, once the teacher has returned the work

   ![The submission list showing assigned date, submit date and published points](./images/view-student-submissions-1.png)

3. Refresh after marking

   If marks are missing, the work may have been marked but not returned in
   Teams, or the assignment may not have been synced since. Run
   [Manual sync from Teams to CE](./manual-sync-from-teams-to-ce.md) again.

   > **Note:** Students without a Microsoft identity never appear in the Team, so
   > they will not appear in the submission list either.
