# Absentee Percentage

Use this feature to view your child's absences as a percentage. 

1. Select Absentee Percentage

   Click the **Attendance** tile on the home screen. Select **Absentee Percentage** from the prompts. Select the child whose record you wish to view. The absentee percentage will automatically display.
