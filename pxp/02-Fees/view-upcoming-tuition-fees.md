# View Upcoming Tuition Fees

Use this feature to view the fees for the upcoming academic year.

1. Select View Upcoming Tuition Fees

   Select the **Fees** tile from the home screen. Select **View Upcoming Tuition Fees** from the prompts. The fees will automatically display.
