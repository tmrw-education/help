# Request an IEP Copy

An Individualised Education Program (IEP) supports learners with learning disabilities. An IEP outlines specialised instruction and any assessment modifications. If your child falls into this category, you can request a copy of their IEP here.

1. Navigate to the student page

   On the home screen, click **Student**. From the suggested prompts, select **Request copy IEP**. Then select the child whose IEP you want to see. The plan will load automatically.
