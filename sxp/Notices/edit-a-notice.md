# Edit a notice

Update a notice you've already created — its details, audience, or visibility.

> **Note:** You can only edit a notice that **you** created.

1. Open Manage notices

   In the **Notices** tab, click **Manage notices** (①) in the top-right corner.

   ![The Notices page with the Manage notices button marked ①](./images/edit_a_notice_1.png)

2. Find your notice

   On the **Manage notices** page, find it in the **Your notices** list (②) — filter
   with the **Active notices** and **Scheduled notices** tiles if it helps — then click
   that notice's **edit icon** (③).

   ![The Manage notices page: the Your notices list ② and a row's edit icon ③](./images/edit_a_notice_2.png)

3. Open the section to edit

   In the **Edit notice details** window, expand the section you want to change —
   **Details**, **Audience type**, or **Visibility** (④).

   ![The Edit notice details window with the Details, Audience type, and Visibility sections ④](./images/edit_a_notice_3.png)

4. Make your changes and save

   Edit the fields as needed (⑤), then click **Save changes** (⑥).

   ![The expanded Details section with editable fields ⑤ and the Save changes button ⑥](./images/edit_a_notice_4.png)
