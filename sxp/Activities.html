Activities

Activity Requests & Management​

Activity coordinator — view all activities​

  1. Navigate to the Activities tab in the Navigation bar.
  2. Scroll below the tiles to All activities.

Activity coordinator — approve all activities​

Teacher — view activity requests​

  1. Navigate to the Activities tab in the Navigation bar.
  2. Scroll below the tiles to Your requests.
  3. All the activity requests are displayed. Check the Status in the column on the right.
  4. Draft requests can be edited or deleted by clicking the appropriate icon.

Note: Each status is colour-coded for quick visual search.

View all activities in calendar format​

  1. Select Activities from the Navigation bar.
  2. Select View Calendar → from the middle tile Calendar view.
  3. At the top right of the calendar, you can view activities for the Month or the Week.
  4. At the top left of the calendar, there are arrow keys to view the Previous or Next month (or week if selected).

View approved venues​

  1. Navigate to the Activities page.
  2. Below the tiles, in the small Navigation bar, select All venues.
  3. The list of approved venues appears below. There are Search and Filter functions to streamline the search.

Request a new venue​

  1. Navigate to the Activities tab from the Navigation bar.
  2. Select Request venue → from the first tile on the left.
  3. Fill in the required fields for Venue Details.
  4. Complete the Risk Management fields.
  5. Review and submit

Note: Incomplete fields will appear with a yellow circle with an exclamation mark. Next to these fields is a pen icon to edit and update them. The Submit button will only become active when all the fields are complete.

Duplicate a previous approved activity​

  1. Navigate to the Activities tab ▸ Your requests.
  2. Click the filter icon on the left. Filter for Approved activities.
  3. Click Apply.
  4. Click the Copy icon (Replicate) to the right of the Status column.
