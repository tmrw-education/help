# Edit or delete a request

You can reopen a request to change it, and delete one you no longer need —
provided it's still a draft. The row action you get depends on the request's
status.

1. Find the request

   On the Activities overview, open your request table — **Your requests** for
   general staff, or **All requests** for coordinators and leaders. Each row
   shows one action icon, set by the request's status.

   {/* CAPTURE: A request table row showing the Edit (pencil) and Delete (bin) actions on a Draft request */}

2. Edit a draft

   Click the **Edit** (pencil) action on a **New / Draft** request. The request
   reopens in the same guided form with your values filled in. Make your changes,
   then **Submit** to send it for approval, or **Save and exit** to leave it as a
   draft.

3. Edit a request that needs more info

   If a coordinator has sent a request back as **More info**, click its name to
   reopen it. The request opens in the form ready to edit; make the changes the
   coordinator asked for and **Submit** to resubmit it.

4. Delete a draft

   Click the **Delete** (bin) action on a **New / Draft** request, then confirm
   in the pop-up. A success message confirms the request was deleted and it
   leaves the list.

   > **Note:** only **New / Draft** requests show Edit and Delete. Once a request
   > is Pending, Approved or Rejected it can't be deleted here — a **Rejected**
   > or **More info** request reopens (to read the review notes or edit) instead.
