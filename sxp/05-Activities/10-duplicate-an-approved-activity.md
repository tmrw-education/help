# Duplicate an approved activity

If you run the same activity again — an annual excursion or a repeat camp —
reuse a past one as the starting point instead of filling in the whole form
from scratch. The new request opens already filled in from the original, so you
only set the new dates and change whatever's different.

1. Find the activity to reuse

   On the **Activities** overview, open the **Your requests** tab and find an
   **Approved** request, then use its row action **Replicate**. You can also
   start from a row in **All activities** using the **Duplicate** action.

   {/* CAPTURE: an Approved request row with the Replicate row action visible */}

2. Open the pre-filled request

   The request form opens **pre-filled** from the activity you chose — the name,
   attendees, location, resource bookings and risk details all carry over. The
   **dates and times are cleared**, so you set fresh ones rather than copying the
   old schedule.

3. Set the new dates and times

   Enter the new **start and end dates** (and the start/end or meeting and pick-up
   times the activity type needs). These are required, so **Submit** stays
   disabled until they're filled in.

4. Adjust anything that's changed

   Work through the steps and update whatever's different this time — student
   groups, lead staff, venue, bookings or risks. Everything is editable; the copy
   is just a starting point.

5. Submit as a new request

   On **Review and submit**, click **Submit**. This creates a brand-new request
   that goes to a coordinator as **Pending** — the original activity is untouched.
