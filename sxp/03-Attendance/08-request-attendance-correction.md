# Correct an already-submitted mark

Once you submit a roll it's locked, so you can't change a mark directly on it. To
fix a mistake, you log a correction request through Felix, which an attendance
officer then reviews and resolves.

1. Ask Felix for a correction

   Open **Felix** and say that you need an **attendance correction** for a **past**
   mark, with the date — for example *I need an attendance correction for 28
   September*. Felix replies with a button to open the **correction form**.

   ![Felix prompted to correct attendance](../10-AI/images/request-an-attendance-correction-with-felix-1.png)

2. Fill in the form and submit

   Pick the **date**, then the **class**, then the **student**, and set the mark
   it should have been — for example from **Present** to **Late**. Submit the
   form, and Felix confirms it has been sent. For each step in detail, see
   [Request an attendance correction with Felix](../10-AI/15-request-an-attendance-correction-with-felix.md).

3. Wait for an officer to resolve it

   Your request goes to an attendance officer's **Correction request** tab, where
   they approve or deny it. It can take a few minutes to appear. The correction
   request is the only way to change a submitted mark — you can't edit the locked
   roll yourself.
