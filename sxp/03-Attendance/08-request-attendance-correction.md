# Correct an already-submitted mark

Once you submit a roll it's locked, so you can't change a mark directly on it. To
fix a mistake, you log a correction request through Felix, which an attendance
officer then reviews and resolves.

1. Ask Felix to correct the mark

   Open Felix and ask for the correction, for example "I need to correct an
   attendance mark" or "fix the roll". Felix confirms that submitted rolls are
   read-only and opens a **correction form** pre-filled for a recent session.

   {/* CAPTURE: Felix chat with a correction request, showing the pre-filled correction form for a recent session */}

2. Set the corrected mark and reason

   In the form, choose the **corrected mark** for the student and add a
   **reason** explaining the change, then submit.

3. Wait for an officer to resolve it

   Your request goes to an attendance officer's **Correction request** tab, where
   they approve and apply the change. The correction request is the only way to
   change a submitted mark — you can't edit the locked roll yourself.
