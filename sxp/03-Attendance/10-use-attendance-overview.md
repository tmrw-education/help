# Use the Attendance overview dashboard

Attendance overview is the whole-school dashboard. School leaders and attendance
officers see it automatically when they open **Attendance** — the same nav item
that opens the teacher calendar for everyone else. Officers see the same
dashboard as leaders, plus an extra set of officer tabs.

1. Open Attendance overview

   Click **Attendance** in the main navigation. As a leader or officer you land
   on **Attendance overview** instead of the teacher page.

   {/* CAPTURE: The Attendance overview dashboard showing the top tile row, the chart row, and the Class rolls list below */}

2. Read the top tiles

   The top row tracks the things needing attention today:

   - **Roll reminders** — the tile label shows a live count of classes that
     haven't submitted yet. Click **View all** to list them by teacher, class,
     period, and outstanding count.
   - **Students at risk** — a live count of students below the attendance
     threshold. Click **View all** to open the at-risk list.
   - **View trends** — jumps to Attendance trends.

3. Read the chart row

   Three charts summarise the day, each with a short summary line:
   **Today's attendance** (a gauge you can filter by Present, Absent, or Late),
   **Attendance errors** (where corrections are coming from), and
   **Attendance category** (the Present / Late / Absent split).

4. Open any class roll

   Below the charts, the **Class rolls** list shows the school's rolls. Search by
   class or teacher, filter by year group, and click a class name to open its
   roll.

5. Work the officer tabs

   If you're an attendance officer, a tab bar sits on the dashboard with
   **Leave requests**, **Class rolls**, **Unresolved attendance**, **Correction
   request**, and **Resolved requests**. Open a tab to work through that queue.
   Leaders see the dashboard without these tabs.
