# Understand onboarding task dependencies

Some onboarding tasks cannot be started until other tasks are finished first — for example, configuring your laptop depends on your Active Directory account being set up. Tasks with unmet dependencies are visible but locked until the prerequisites are done.

1. Identify a blocked task

   In your task list, a task that has unresolved dependencies will show clearly that it cannot be progressed yet.

2. Open the blocked task

   Click on the task to open its detail view.

3. Review the dependencies

   The detail view shows:
   - The list of dependency tasks that must be completed first
   - The current status of each dependency
   - Who each dependency is assigned to
   - The target completion date for each dependency

   ![The blocked task detail view showing the list of dependencies, each with its owner, status, and due date](./images/understand-task-dependencies-1.png)

4. Wait for dependencies to clear

   You cannot complete the blocked task until all listed dependency tasks are finished. If a task is overdue, contact the person responsible for the dependency to follow up.
