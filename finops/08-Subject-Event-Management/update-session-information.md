# Update the Session Information

When a student attends more or fewer sessions than originally invoiced, update the session record status to Change, enter the revised session count, and run the adjustment batch. The system calculates the difference and creates an updated sales order.

1. Update the session record

   From the **FNO dashboard**, open **Modules ▸ Academic Management**, expand **Inquiries and reports ▸ Fee schedules**, and click **Sessional class and events details**. Locate and select the record requiring adjustment.

   Open the **Change status** dropdown in the toolbar and change the status to **Change**. Enter the revised number of sessions in the **Updated sessions** column and click **Save**.

2. Generate the adjustment

   See [Generate the Session Adjustment](./generate-session-adjustment.md) to create the adjusted sales order.
