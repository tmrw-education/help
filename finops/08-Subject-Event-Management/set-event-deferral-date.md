# Set the Deferral Date

A deferral date must be set against the event record before generating invoices. Until that date the charge is held in a deferred revenue account; once the event date passes, the system automatically transfers the balance to the main revenue account.

1. Open the event record

   From the **FNO dashboard**, open **Modules ▸ Academic Management**, expand **Setup**, and click **Subject and event names**. Locate and select the relevant event record.

2. Set the deferral date

   Click **Deferrals**, enable the **Deferred** toggle, and set the **Deferral date** to the event date. Click **OK**.
