# Enrol a Student in a Sessional Class or Event

Once subject and event codes are in place, a fee schedule template must be created to link the specific event code to the correct fee item. The template uses conditions to restrict invoice generation to students enrolled in that event.

1. Create a new fee schedule template

   From the **FNO dashboard**, open **Modules ▸ Academic Management**, expand **Fee schedules**, and click **All fee schedules**. Click **New** in the toolbar.

   Enter a **name** for the template (e.g., *Zoo Excursion Fee*), choose the **Billing interval**, and match **Early payment discounts** with the fee categories.

2. Add the fee line and condition

   Click **+ Add line** and complete the line:

   - **Item number** — select the relevant fee item.
   - **Apply to** — change to *Sessional class and event*.
   - **Conditions** — enable the checkbox.

   Click **Condition** in the toolbar. In the line with **Code** in the Field column, enter the event code in the **Criteria** column by clicking **+**, then click **OK**.

3. Save

   Click **Save**.
