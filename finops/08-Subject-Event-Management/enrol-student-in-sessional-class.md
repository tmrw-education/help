# Enrol a Student in a Sessional Class or Event

Once the subject and event codes are in place, a fee schedule template must be created to link each event code to the correct fee item. The template uses conditions to restrict invoice generation to students enrolled in that event.

1. Create a new fee schedule template

   From the **FNO dashboard**, open **Modules ▸ Academic Management**, expand **Fee schedules**, and click **All fee schedules**. Click **New** in the Action Pane.

   Enter a **Description** for the template (e.g., *Zoo Excursion Fee*) (④), choose the **Billing interval**(⑤), and match **Early payment discounts** with the fee categories (⑥).

   ![Enrol Student in Sessional Class — the fee schedule template with Apply to set to Session class and event and the Conditions checkbox enabled](./images/enrol-student-in-sessional-class-1.png)

2. Add the fee line and condition

   Click **+ Add line** (⑦) and complete the line (⑧):

   - **Item number** — select the relevant fee item.
   - **Apply to** — change to *Session class and event*.
   - **Condition** — enable the checkbox.

   Click **Condition** in the toolbar (⑨). In the line with **Code** in the Field column, enter the event code in the **Criteria** column (⑩) by clicking **+**, then click **OK** (⑪).

   ![Enrol Student in Sessional Class — the Condition query dialog with the event code entered in the Criteria column](./images/enrol-student-in-sessional-class-2.png)

3. Save

   Click **Save**.
