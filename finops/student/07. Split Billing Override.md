# Split Percentage by Items

## What you’ll do
Assign specific fee split percentages to each payer for individual fee items, allowing for customized billing arrangements beyond the default setup.

---

## Setup student financial responsibility

1. From the **FNO dashboard**, open **Modules** ▸ **Academic Management**.
2. Expand **Students** and click **All students**.
3. Select the student profile.
4. Under the student’s account in the **Relationships** section, ensure at least two fee payers are assigned (e.g., *Mom* and *Dad*).
5. Assign default split percentages for each payer (e.g., `50%` each).  
   - **Note:** This is the baseline for all fees unless overridden.

---

## Create split billing fee schedule template

1. Go back to **Modules** from the sidebar.
2. Select **Academic Management**.
3. Expand **Fee schedules** and click **All fee schedules**.
4. Click **New** to create a new template (e.g., `Split billing override template`).
5. Set the **Billing interval** (e.g., termly).
6. Enable the **Early payment discount** option if required.
7. In the **Fee schedule lines** section, click **Add line**.
8. Choose the **Product name** (e.g., *Tuition fee*).
9. Enable **Conditions** and click **Condition** in the toolbar.
10. Set the **Criteria** for any necessary conditions (e.g., applies to current academic year students).
11. Add any other fee items required (e.g., *Building Fund Fee* item, which can be set to apply to all students without conditions).
12. Click **Save**.

---

## Configure split percent by fee items

1. Go back to **Modules** from the sidebar.
2. Select **Academic Management**.
3. Expand **Setup** and click **Split percent by fee items**.
4. Click **Add** to create a new record for a student.
5. Search and select a student.
6. Select the specific **Fee item** to override (e.g., *Building Fund Fee*).
7. Assign the custom split percentages for each payer (e.g., *Dad 60%*, *Mom 40%*).
8. Specify the **Effective** and **Expiration** dates for this split configuration.
9. Repeat these steps for the other payer.
10. Click **Save**.
