# Replace an old report viewer grant

An older role, listed as **Old report viewer (no effect)**, gives nothing beyond what a learner has. It isn't upgraded
automatically, so nobody gets access that wasn't reviewed. Replace it with **Report viewer**, or remove it.

You need the **Organisation administrator** role.

1. Find the old grants

   Go to **Manage** → **Access and permissions**. In **Who has access**, set **Role** to **Old report viewer (no
   effect)**.

2. Give Report viewer

   If the person should see reports, click the give icon on their row. **Give access** opens with the person and
   **Report viewer** already chosen. Change **Where** to one unit if they should only see part of the organisation, then
   click **Give access**.

3. Remove the old row

   Click the remove icon on the **Old report viewer (no effect)** row, then **Remove access**.
