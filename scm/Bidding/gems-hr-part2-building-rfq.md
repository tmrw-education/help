# Part 2 — Building the RFQ / RFP

This section covers everything you need to complete before publishing. You will write the project documents, configure pricing, add vendors, and set up internal access and compliance checks.

1. Write the Project Introduction

   The introduction is the first thing vendors read, so it should explain what is being procured and any context they need. You have three options:

   - **Introduction field** — type the introduction directly.
   - **Import from Library** — copy a saved introduction from a previous project.
   - **Generate Introduction** — use the **AI Generator**: type a short scope description, click **Generate**, review the output, and click **Apply** if it looks right.

   > **Note:** *The AI generator works best with specific input. Always review the result before applying it.*

2. Add the Technical Document

   The technical document contains the specifications vendors must meet to submit a valid bid. Click **Attach Document** to upload a PDF or Word file, or click into the text entry area to type specifications directly. Make sure every requirement is clearly stated — vendors will use this as their reference for everything they submit.

   > **Note:** *Do not publish until this section is complete.*

3. Add Terms and Conditions

   Click **Import Template** and select the appropriate template for this procurement type (services, goods, IT, and so on). Review the terms and make any amendments specific to this engagement. If no template applies, click **New Terms and Conditions** and draft them directly in the text editor. Save before moving on.

4. Configure the Price Bid

   Select the bid **Currency** from the dropdown. The line items will have been imported from the PR you linked in Part 1 — review each one for description, quantity, and unit of measure, and adjust or add items as needed. If price weighting was enabled, confirm the percentages are applied correctly and sum to 100%.

   > **Note:** *The currency cannot be changed after vendor invitations have been sent.*

5. Add Vendors

   Click **Add Vendor** and search the approved vendor list. You can also add prospective vendors at this stage — vendors not yet fully onboarded. They will receive the invitation email and can bid, but their onboarding must be completed before any contract can be awarded to them.

   > **Note:** *As soon as you add a prospective vendor, follow up on their onboarding in parallel — do not leave it until the award stage.*

6. Add Collaborators

   Click **Add Collaborator** and search for the internal user by name or email. Set their access level:

   - **Full access** — for users who need to take actions in the project.
   - **View-only** — for users who only need to monitor it.

   > **Note:** *Keep access levels to what is genuinely necessary.*

7. Select Risk Assessments

   Click **Add Assessment** and review the available questionnaires. Select those relevant to the vendor type and procurement category — a service company will not need the same assessments as a product supplier. Only add what is genuinely applicable to this engagement.
