# tmrw Help

The knowledge base and help site for the tmrw education platform.

**Live site:** https://tmrw-education.github.io/help/

---

## Apps covered

| Section | App | Audience |
|---|---|---|
| `/sxp` | StaffXP | Teachers, admin, school leaders |
| `/ess` | Employee Self-Service | All staff (HR) |
| `/fo` | Finance & Operations | Bursars, accountants |
| `/pxp` | Parent Experience | Parents |
| `/lxp` | Learner Experience | Students |

## How it works

Content is written in Markdown. Every push to `main` auto-deploys to GitHub Pages via GitHub Actions.

See `_internal/AUTHORING_FOR_FELIX.md` for content authoring guidelines.

## Local development

```bash
npm install
npm start
```

## Internal docs

Team docs (strategy, authoring guide, release notes) live in `_internal/` — not published to the site.
