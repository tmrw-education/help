# Configure personal action types for onboarding

The Personal action types form controls which hire action types trigger the automatic application of an onboarding checklist when a worker action is completed. This flag must be enabled on each relevant action type.

1. Open Personal action types

   In D365, search for and open **Personal action types**.

2. Locate the hire action type

   Filter or scroll to find the action type used for new hires — for example, *Regular*.

3. Enable the checklist flag

   Enable the **Apply onboarding checklist** flag (or equivalent setting in the **Apply on** field) for this action type. When a worker action of this type is completed, the system will automatically apply the nominated onboarding checklist to the new employee record.

   ![The Personal action types list with the regular hire action type selected and the Apply onboarding checklist flag enabled](./images/configure-personal-action-types-1.png)

4. Save

   Click **Save**.

   Repeat for any additional action types that should trigger onboarding checklist assignment.
