# Submit leave requests in bulk

When a whole group needs the same leave booked—for example, a scheduled closure for teaching staff—HR can submit requests in one pass rather than asking each employee to raise their own.

1. Open the bulk request form

   In D365, go to **Leave and absence ▸ Manage leave ▸ Bulk request time off**.

   ![The Bulk request time off form in D365](./images/submit-bulk-leave-requests-1.png)

2. Select the leave details

   Choose the **Leave plan** and **Leave type** that can be booked, and select the **Reason code** if the type requires one.

3. Set the dates

   Enter the **Start date** and **End date** of the period to be booked. The same dates apply to everyone included in the run.

4. Filter the worker list

   Narrow the list to the group you are booking for. Filters are available for **Position type**, **Department** and **Staff category** — for example, filtering department to all stages, or staff category to admin support.

   ![The bulk request worker list filtered by department and staff category](./images/submit-bulk-leave-requests-2.png)

   Use **Clear** to reset the filters and start again.

5. Select the workers

   Tick the individual workers to include, or use **select all** to take everyone left after filtering. Check the selection before continuing — the requests are created immediately and approved without review.

6. Assign the leave

   Click **Assign leave**. A leave request is created for every selected worker.

7. Confirm the requests are completed

   The requests are created as system-generated, so the workflow condition approves them automatically rather than routing them to managers. Give the process a moment, then check the results either on an individual employee's time off requests or on the main time off requests list, where all of them are visible together.

   ![The time off requests list showing the bulk-created requests completed](./images/submit-bulk-leave-requests-3.png)

   If the requests stay in review, the workflow is missing the auto-approval condition —see [Configure the leave approval workflow](./02-configure-leave-approval-workflow.md).
